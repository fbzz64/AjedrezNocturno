# AjedrezNocturno ♟️

Una aplicación web para resolver problemas de ajedrez aleatorios de Lichess con datos curiosos sobre el ajedrez.

## Características

- 🎯 Problemas de ajedrez aleatorios de la base de datos de Lichess
- 🎲 Datos curiosos sobre ajedrez, jugadores y torneos
- 🎨 Interfaz moderna y responsive
- ♟️ Tablero interactivo para resolver los problemas

## Cómo usar

1. Abre `index.html` en tu navegador
2. El problema de ajedrez se cargará automáticamente
3. Haz clic en "Nuevo Problema" para cargar otro
4. Lee los datos curiosos que aparecen en cada carga

## Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)
- Lichess API
- chess.js (lógica del ajedrez)
- chessboard.js (visualización del tablero)
